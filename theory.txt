условные операторы. (if, else if, else)
if (условие) { блок кода 1}
else if (условие) {блок кода 2}
else {блок кода 3}
условные операторы позволяют выполнять различные действия в зависимости от выполнения или не выполнения определенных условий.

оператор if () исп для выполнения кода если указанные условия истинно.
оператор else if () используется для выполнения доп условий, если прошлые условия не были истинными.
оператор else нет условия, исп для выполнения кода, если ни одно из предыдущих усл не было выполнено.

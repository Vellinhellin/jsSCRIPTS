1. ПЕРЕМЕННЫЕ - это именновоное хранилище для данных
в js есть 3 переменных
let - локальная переменная
var  - глобальная переменная
const - неизменяемая и непереопределяеммая переменная (констата)

let a=5
let b=3
c=a+b
console.log(c)

let var const - операторы объявления
по умолчанию пременные объявляются как глобальные (а = 5)

## 1. Введение и особенности JS

### 🌐 Среда выполнения
- Изначально — **браузер** (встраивается в HTML, выполняется автоматически при загрузке страницы).
- Сейчас — **сервер** (Node.js) и любые устройства (движок V8).

### ⚙️ Ключевые особенности
- **Интерпретируемый язык**: Код — это простой текст, **компиляция не нужна**.
- **Стандарт**: Описан в спецификации **ECMAScript (ECMA-262)**.
- **Типизация**: **Слабая / динамическая** (не строгая). Для строгой типизации используется **TypeScript**.

### 🖨️ Вывод данных
| Метод | Описание |
| :--- | :--- |
| `alert("Привет, мир!")` | Всплывающее окно в браузере. |
| `console.log("Привет, мир!")` | Вывод в консоль разработчика (F12). |

### 💬 Комментарии
- `//` — Однострочный комментарий.
- `/* ... */` — Многострочный комментарий.

## 2. Переменные

> **Определение**: Именованное хранилище для данных.

| Оператор | Область видимости | Особенность |
| :--- | :--- | :--- |
| **`let`** | Блочная `{...}` | Можно изменять. Основной способ объявления. |
| **`var`** | Функциональная / Глобальная | **Устарел**. Подвержен "всплытию" (hoisting). |
| **`const`** | Блочная `{...}` | **Нельзя переопределять**. Используется для констант. |

> ⚠️ **Важно**: `a = 5` (без оператора) создает **глобальную** переменную (плохая практика).

## 3. Типы данных

### 🔢 Примитивные типы
| Тип | Пример | Примечание |

## 5. Преобразование типов

### 🔄 Способы приведения к числу
```javascript
let a = "123";
Number(a);          // 123
parseInt("3.14");   // 3 (целое)
parseFloat("3.14"); // 3.14 (дробное)
+"3.14";            // 3.14 (Унарный плюс — быстрый способ)
```
### 🔍 Проверка типа
```javascript
typeof 123;      // "number"
typeof "Hello";  // "string"
```

## 6. Операторы

### 🧮 Математические
`+` , `-` , `*` , `/` , `**` (степень), `%` (остаток от деления).

### ⚖️ Сравнения
| Оператор | Значение | Пример (`a = '23', b = 23`) |
| :--- | :--- | :--- |
| `==` | Равно (с приведением типов) | `a == b` → `true` |
| `===` | **Строгое равенство** (без приведения) | `a === b` → `false` |
| `!=` | Не равно | `a != b` → `false` |
| `!==` | Строгое не равно | `a !== b` → `true` |

### 🧠 Логические
- **`&&`** — **И** (Логическое умножение). *Оба условия должны быть true*.
- **`||`** — **ИЛИ** (Логическое сложение). *Хотя бы одно true*.
- **`!`** — **НЕ** (Отрицание). `!true` → `false`.

## 7. Условные конструкции

### 🔀 if / else if / else
```javascript
if (условие) {
  // Код, если условие истинно
} else if (другое_условие) {
  // Код, если первое ложно, а это истинно
} else {
  // Код, если всё ложно
}
```

### ❓ Тернарный оператор
*Упрощает простую проверку на два варианта.*
```javascript
let result = (x > y) ? 'x больше y' : 'x меньше или равен y';
```

### 🔁 Switch / Case / Default
*Удобен для сравнения с конкретными значениями.*
```javascript
switch (a) {
  case 3:
    alert('Мало');
    break; // Обязательно прерывать!
  case 4:
  case 5: // Объединение кейсов
    alert('В точку');
    break;
  default:
    alert('Мимо');
}
```

## 8. Циклы

### 🔄 Виды циклов
| Конструкция | Описание |
| :--- | :--- |
| `while (i < 10) { ... }` | С предусловием. Может не выполниться ни разу. |
| `do { ... } while (i < 10);` | С постусловием. Выполнится **минимум 1 раз**. |
| `for (let i=0; i<10; i++) { ... }` | Классический цикл со счетчиком. |

### ⛔ Управление циклом
- **`break`** — Немедленный выход из цикла.
- **`continue`** — Пропустить текущую итерацию, перейти к следующей.
   *Пример (вывод только нечетных):*
   ```javascript
   for (let i = 0; i <= 10; i++) {
       if (i % 2 == 0) continue;
       alert(i);
   }
   ```

## 10. Массивы (Array)

### 🗂️ Создание
`let array = [-3, 0, 3.14, "string", true];`

### 🛠️ Основные методы
| Метод | Действие | Пример |
| :--- | :--- | :--- |
| `push(item)` | Добавить **в конец** | `arr.push(10)` |
| `pop()` | Удалить **с конца** | `arr.pop()` |
| `unshift(item)` | Добавить **в начало** | `arr.unshift('hi')` |
| `shift()` | Удалить **с начала** | `arr.shift()` |
| `length` | Длина массива (свойство) | `arr.length` |
| `indexOf(item)` | Найти индекс элемента | `arr.indexOf('string')` → `3` или `-1` |

### ⚡ Продвинутая работа (Функциональные методы)
*Все эти методы возвращают **новый** массив или значение, не изменяя исходный.*

| Метод | Описание |
| :--- | :--- |
| `filter(fn)` | Фильтрация. Оставляет только элементы, прошедшие проверку. |
| `map(fn)` | Трансформация. Преобразует каждый элемент (например, `* 2`). |
| `forEach(fn)` | Перебор. Просто выполняет действие для каждого элемента. |
| `concat(arr2)` | Слияние массивов в один новый. |
| `slice(start, end)` | Возвращает копию участка массива (от `start` до `end`, не включая `end`). |

## 11. DOM (Document Object Model)

> Работа с HTML-элементами на странице.

### 🔍 Поиск элементов
| Метод | Что ищет | Пример |
| :--- | :--- | :--- |
| `getElementById` | По ID (один элемент) | `document.getElementById("first")` |
| `querySelector` | По CSS-селектору (**первый**) | `document.querySelector(".myBtn")` |
| `querySelectorAll` | По CSS-селектору (**все**) | `document.querySelectorAll("div")` |

### ✏️ Изменение содержимого и стилей
```javascript
const elem = document.getElementById("first");

// Содержимое
elem.innerHTML = "<h1>Заголовок</h1>"; // Вставляет HTML-код
elem.textContent = "Просто текст";     // Вставляет только текст (безопаснее)

// Стили (CSS)
elem.style.background = "red";
elem.style.color = "white";
elem.style.fontSize = "20px";
```

### 🖱️ События (Events)
```javascript
const btn = document.querySelector('.myBtn');

function clicker() {
  alert('Кнопка нажата!');
}

btn.addEventListener('click', clicker);
```

### 🏷️ Классы и Атрибуты
```javascript
// Работа с классами
elem.classList.toggle('active'); // Добавит класс если его нет, уберет если есть.

// Установка атрибута
elem.setAttribute("disabled", "true");
```
